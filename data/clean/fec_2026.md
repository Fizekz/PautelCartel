# fec_2026.csv / fec_race_2026.csv: FEC fundraising, 2026 general-election candidates

Built by `src/data/fetch_fec.py` (run `.venv/bin/python src/data/fetch_fec.py`; add `--refresh` to re-download).
Pulled 2026-11-01. FEC's S3 `Last-Modified` on `weball26.zip` was 2026-11-01 05:44 UTC.

## Sources
- FEC bulk "All candidates" summary for 2025-2026: https://www.fec.gov/files/bulk-downloads/2026/weball26.zip
  (it redirects to the FEC's S3 bucket). Raw copy: `data/raw/fec/weball26.zip`.
- FEC candidate master for 2025-2026: https://www.fec.gov/files/bulk-downloads/2026/cn26.zip. Raw copy: `data/raw/fec/cn26.zip`.
  Header: https://www.fec.gov/files/bulk-downloads/data_dictionaries/cn_header_file.csv (`data/raw/fec/cn_header_file.csv`).
- FEC committee master for 2025-2026: https://www.fec.gov/files/bulk-downloads/2026/cm26.zip (`data/raw/fec/cm26.zip`,
  header `cm_header_file.csv`). Used only to drop duplicate candidate ids that share one principal committee.
  The weball header file is not on the server (404), so its 30 columns are hard-coded from the FEC data dictionary.
- Names and ballot slots: `data/kalshi/races_2026-11-01T074812Z.csv` (column `candidates`). Kalshi decides who is on
  the ballot here. It is **not** model input. Race list: `data/templates/full_congress_template.csv`.
- I did not use the OpenFEC API.

## fec_2026.csv (951 rows, all 470 race_ids)
There is one row per Kalshi candidate slot. Every Kalshi slot is kept, so the file is a ballot list with FEC money
joined on. FEC candidates who match no Kalshi slot (mostly primary losers) are dropped.

| column | meaning |
|---|---|
| race_id, chamber | template key |
| cand_id, candidate_name | FEC id and name (blank when unmatched) |
| party | Kalshi's party label (DEM/REP/IND). Where Kalshi says UNK (same-party top-two races in CA/WA), this is the FEC party bucket |
| incumbent_challenger_open | FEC CAND_ICI: I / C / O |
| receipts, disbursements, cash_on_hand | weball TTL_RECEIPTS, TTL_DISB, COH_COP, in USD, for 2025-01-01 through coverage_end_date |
| coverage_end_date | end of the latest report in the summary. 872 of the 892 rows with financials end on 2026-10-14, which means the pre-general report is included |
| kalshi_name_match | match quality (see below) |
| kalshi_name, fec_party, fec_office_district, fec_election_yr | extra audit columns. Read the district as a string |

Match labels:
- `exact` (922): surname and given name agree. Given names count as agreeing through nicknames, prefixes or
  middle names, and a match holds even when FEC swapped first and last name. All exact matches are in the same
  office and district as the race.
- `last_name_initial` (1, TX-06 Jake Ellzey = ELLZEY, JOHN KEVIN SR.) and `last_name_only` (3): AZ-01 Jay Feely =
  FEELY, THOMAS JAMES; NM-01 Didi Okpareke = OKPAREKE, NDIDIAMAKA; PA-16 Mike Kelly = KELLY, GEORGE J JR. A
  surname-only match is accepted only when office, district, party and election year 2026 all agree. I checked all four by hand.
- `generic_party_active_incumbent_fec` (6) and `generic_party_sole_active_fec` (3): Kalshi lists only "Democratic
  party" or "Republican party". The slot is filled with that party's 2026 incumbent for the seat, or else with the
  only campaign of that party that has at least $5,000 in receipts and a report ending 2026-09-30 or later. Filled
  slots: AK-SEN (Peltola D, Sullivan R), LA-01 (Scalise R, Jewett D), LA-02 Carter D, LA-03 (Higgins R, Day D),
  LA-04 Johnson R, LA-06 Fields D. These are **assumptions** and should be checked.
- `generic_party_no_name` (15): no name and no single active FEC campaign. The FEC fields are blank. This covers
  AZ-03 R, CA-06 R, FL-10 R, LA-02 R, LA-04 D, LA-05 D and R, LA-06 R, MA-01/02/05/07 R, NJ-08 R, PA-03 R and WI-02 R.
  The MA, NJ-08 and WI-02 R slots have no 2026 FEC filer at all, so they are probably uncontested or nominal.
- `no_fec_match` (1): MD-04 R George McDermott is not in cn26.

Of the 935 matched rows, 43 have **blank receipts**. These candidates are in the candidate master but have no
financial summary, usually because they raised less than the $5,000 filing threshold. Almost all are minor-party
or long-shot challengers.

## fec_race_2026.csv (470 rows)
`race_id, dem_receipts, rep_receipts, ind_receipts, dem_share_receipts, log_ratio, n_kalshi_slots, n_unmatched, n_no_fin, receipts_basis`
- `receipts_basis = kalshi_slots` (464 races): the sums run over fec_2026 rows by `party`, and IND = every slot that
  is not DEM or REP. Unmatched and no-financial slots count as $0.
- `receipts_basis = all_active_party_filers` (the 6 Louisiana House seats): Louisiana's Nov 3 House contest is an
  all-party open primary (Dec 12 runoff if nobody gets 50%), and Kalshi prices only the winning party. The sums
  are therefore every 2026 FEC filer of that party in the district whose latest report ends 2026-09-30 or later
  (this drops withdrawn campaigns such as Letlow's old LA-05 committee). The first build summed only the one
  assumed candidate per party, which gave LA-06 a dem share of 1.0 (no R matched) while Kalshi has R at 0.95, and
  left LA-05 blank. Now: LA-04 0.085, LA-05 0.052, LA-06 0.104. `n_unmatched`/`n_no_fin` still describe the slot
  matching in fec_2026, so do not use them to mask these 6 races. `n_unmatched` counts slots with no FEC id and `n_no_fin` counts matched slots
  with blank receipts, so either one can be used to mask the race.
- `dem_share_receipts = dem/(dem+rep)`. It is never blank now (it was blank for LA-05 before the fix).
- `log_ratio = ln((dem + 1) / (rep + 1))`, a natural log with $1 smoothing. When one side has no candidate it runs to
  about ±17 (same-party top-two races, uncontested races, unnamed slots), so clip or winsorize it before modelling.
- Same-party top-two races (for example CA-04 D vs D, CA-40 R vs R) give a share of 1 or 0 by construction.

## Caveats
- **Senate totals cover only 2025-2026.** weball is a two-year summary, so a senator's money raised in 2021-2024
  is missing. Incumbent-vs-challenger comparisons are biased toward challengers. Incumbents' cash_on_hand still
  includes the carried-over balance.
- Receipts include candidate self-loans, candidate contributions and transfers between authorized committees.
  There is no outside spending (super PAC or party IE) anywhere in these files.
- **Redistricting (TX, CA Prop 50, MO, NC, OH, UT and others):** FEC district codes in cn26 are already on the 2026
  lines for every matched House candidate. No matched candidate's FEC district differs from the race_id. One
  example: Calvert's id H2CA37023 is filed under CA-40. FEC ids keep their original district digits
  (H6LA05234 Miguez runs in LA-06), so never parse districts from ids.
- **Louisiana:** after Louisiana v. Callais (Apr 29 2026) the state cancelled its spring congressional party
  primaries, redrew the map and put all House candidates on a Nov 3 open primary with a Dec 12 runoff (WAFB
  2026-05-14, Ballotpedia News 2026-09-05: 39 candidates in six districts). So there are no nominees, which is why
  Kalshi lists parties only. The LA rows in fec_2026 name one candidate per party (incumbent or sole active
  filer) and are only a convenience; use the all-filer party sums in fec_race_2026. LA lines changed (LA-05 ids
  now file in LA-06). Julia Letlow (LA-05 incumbent) is running for LA-SEN.
- AK and ME use ranked-choice voting; CA and WA use top-two. Kalshi lists 2 to 4 slots per race.
- FEC party codes are messy: Kiley CA-06 is `OTH` (Kalshi lists him as IND), Risch is `UNK`, Burbank NE-SEN is
  `DE`, Chaffee is `REO`. Use `party` (from Kalshi), not `fec_party`.
- Some people have both an H and an S id that share one principal committee, so weball repeats the same totals
  under both (Hinson H0IA01174 / S6IA00314, Pappas, Barr, Carter, Collins; 173 such extra ids in cn26). The script
  now keeps only the id the committee master links the committee to (`drop_shared_pcc_duplicates`). This changed
  one 2026 row: NV-03 Marty O'Donnell now uses H4NV03225 ($4,835,730) and not H6NV03204 ($4,864,563). Both ids
  share his committee, so the totals differ by only $29k.
- weball26 also contains senators not up until 2028/2030 and 2026 primary losers. Neither is in this file.

## Verification (independent check, 2026-11-01)
- Schema, 470/470 race_ids in both files, no duplicate cand_ids, chambers agree with the template, H/S id prefix agrees
  with chamber, every matched House row's FEC district equals the race_id seat, and per-race sums recompute exactly.
- 10 random matched rows (NY-01 Gallant, RI-02 Magaziner, AZ-08 Hamadeh, NJ-10 McIver, GA-07 Kozycki, MS-01 Kelly,
  GA-08 Esti, PA-05 Manganaro, FL-03 Cammack, AZ-07 Butierez) match the OpenFEC `/candidate/{id}/totals` API
  (cycle 2026) to the cent for receipts, disbursements, cash on hand and coverage date. More API checks were
  blocked by the DEMO_KEY limit (40 calls/hour).
- Hand-picked checks against news: SC-SEN Darline Graham (R) is the nominee after Lindsey Graham's death (AP via
  Local10, Aug 26 2026) vs Annie Andrews (D); CA-04 is Thompson vs Eric Jones, both D (Ballotpedia News, Jun 15
  2026), and Jones outraised Thompson in every report found; CA-40 is Kim vs Calvert, both R, and Kim leads in money
  as reported (NOTUS/legis1); OH-SEN special: Brown outraises Husted (Spectrum News, Oct 15 2026), as in the file
  ($68.4M vs $19.9M); Louisiana: see above.
- Kalshi cross-check: the correlation of Kalshi's D win probability with dem_share_receipts is 0.92. After the
  Louisiana fix, no race has Kalshi above 0.9 for one party while the receipts share is below 0.2 for that party.
